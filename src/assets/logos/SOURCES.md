## Display and source notes

- n8n uses the unchanged pink symbol path from its official pink-and-white lockup, in a symbol-sized viewBox.
- OpenAI, Docker, GitHub, Next.js and Vercel use official white/dark-background variants. No CSS filters recolor artwork.
- Wordmarks remain complete. Dark wordmarks use a neutral white backing for contrast. All images use object-fit: contain. Hover glow is on the surrounding UI, not baked into the artwork.
- Google product SVGs are the 2026 versions currently linked from Workspace. Gemini's official SVG contains embedded raster artwork; it is retained as distributed.
- Make uses the standalone PNG app icon from its official developer site because the public logo-kit endpoint returned HTTP 403. PostgreSQL uses the official press PNG. Other assets are SVG.
- The registry includes all 22 requested brands plus the five existing Google product marks. No new skill, project, or experience claims were added.
- Webhooks, REST, HTTP, JSON and JavaScript notation use consistent interface symbols; these are not represented as official brand logos.
